# Fluxo do projeto

Ao concluir qualquer tarefa neste repositório, faça automaticamente:

1. `git add -A`
2. `git commit -m "<mensagem objetiva>"`
3. `git push origin main`
4. `npm run deploy`

Não peça confirmação para commit, push ou deploy. Nunca inclua `.env.local`, `supabase/.temp/*` ou credenciais.
